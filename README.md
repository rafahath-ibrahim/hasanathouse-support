# Hasanat House — Support

The support page for the [Hasanat House](https://apps.apple.com/app/id0000000000) iOS
and Android app, served at
<https://rafahath-ibrahim.github.io/hasanathouse-support/>.

This URL is what App Store Connect and Google Play Console list as the app's
Support URL, so it must keep resolving for as long as the app is published.

The FAQ answers describe real flows in the app (Profile → Delete account, Blocked
accounts, Change password, and the email-change verification code). If any of
those move, update this page too — a support page that describes buttons that no
longer exist is worse than none.

The privacy policy lives in Notion rather than here, and is linked from the footer.
